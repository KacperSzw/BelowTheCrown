# Below the Crown

The original castle: an indebted jailer, unpaid watch, diverted wages and a king
who mistakes fear for loyalty. The prisoner begins with one guard in the dungeon.

A pantry letter is physical evidence. Real bargaining, theft, subdual, disguise,
crafting and poisoned-food delivery can create opportunities. None grants an
outcome through a text note alone. Captain Marcus / Marek is male and retains
ID 104. Private secrets remain in individual starting minds.
